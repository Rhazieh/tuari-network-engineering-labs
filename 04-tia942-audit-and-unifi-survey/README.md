# 04 — Data Center Audit (TIA-942), Outdoor Wi-Fi Survey (UniFi Mesh) & System Assessment

Applied infrastructure field surveys and technical evaluations executed on the **UNICEN University Campus** (`Eje de Aplicación / Proyectos` — TUARI, UNICEN).

---

## Projects Summary

### 1. UNICEN Data Center Audit (`ANSI/TIA-942`)
- Assessed the university campus data center across the **four TIA-942 subsystems**:
  1. **Architectural** (physical access, layout, structural safety)
  2. **Electrical** (power redundancy, UPS/backup paths, distribution)
  3. **Mechanical** (cooling airflow, thermal control, HVAC resilience)
  4. **Telecommunications** (cabling pathways, rack organization, link redundancy)
- Identified single points of failure and documented actionable reliability improvements.

### 2. Campus Green-Space Wi-Fi Coverage Study (`Ubiquiti UniFi Mesh`)
- Conducted on-site **RSSI** signal measurements and coverage-zone mapping across outdoor green areas of the UNICEN Tandil campus.
- Designed an outdoor wireless deployment architecture based on **Ubiquiti UniFi Mesh** access points, PoE (`802.3af/at`) budgets, and roaming/coverage thresholds.

### 3. Functional Infrastructure & Software Comparative Analysis (`phpScheduleIt` vs `Booking Scheduler`)
- Interviewed Data Center administrators, documented operational requirements across application versions, built **SWOT (FODA)** matrices, and evaluated infrastructure modernization impact.
